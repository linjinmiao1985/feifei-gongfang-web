# 飞飞工坊 · 网页试玩版

在线试玩：https://linjinmiao1985.github.io/feifei-gongfang-web/

2D 侧视化学粒子沙盒：撒分子、看反应、捏出星球、拼装置，再让生命演化。用 Godot 4.6 导出（Compatibility 渲染器，单线程）。建议用电脑上的 Chrome / Edge 打开，第一次加载约 40 MB。

## 操作（以游戏代码为准）
| 按键 | 功能 |
|---|---|
| 鼠标左键 | 使用当前工具 |
| 鼠标滚轮 / = - | 缩放视角 |
| WASD / 方向键 | 移动视角 |
| 1 | 喷射（发射器） |
| 2 | 生命（Shift+2 切换营养级） |
| 3 / 4 | 绳子 / 电线 |
| 5 | 橡皮 |
| 6 | 喷火加热 |
| 7 | 引力 |
| 8 | 切换自定义工具 |
| 9 | 零件 |
| 0 | 缩放工具（选中物体放大/缩小） |
| V / G | 方块 / 焊接 |
| [ ] | 笔刷大小 |
| Tab | 物质选择器 |
| E | 选中天体后进入/离开地表 |
| R / F / J / H | 装置：点火 / 燃料箱 / 关节 / 关节驱动 |
| K / L / ; | 装置：开关 / 切换信号类型 / 接信号 |
| B | 保存装置 |
| P | 固定/取消固定 |
| , / . | 时间流速 慢 / 快 |
| Y | 成就 |
| C | 清空场景；Ctrl/Cmd+Z 撤销 |
| F5 / F9 | 快速存档 / 读档 |
| F6 / F7 | 力场模式 / 深物理开关 |

注：网页版里 Tab、F5 等键可能被浏览器占用，玩之前先点一下游戏画面；F5 在浏览器里可能会刷新页面，建议全屏后再用。
